# AI Voice Assistant

This is a simple AI voice assistant built using Python. It supports speech recognition, text-to-speech, and basic commands like:
- Checking time and date
- Searching Google
- Getting Wikipedia summaries
- Opening Notepad

## Installation

Run the following command to install dependencies:

```
pip install -r requirements.txt
```

## Usage

Run the assistant using:

```
python main.py
```

Say "exit" to stop the assistant.
